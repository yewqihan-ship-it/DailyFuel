# DailyFuel website — first draft

## Open in VS Code
1. Extract this ZIP.
2. Open the DailyFuel folder in VS Code (File > Open Folder).
3. Open index.html in your browser, or use VS Code Live Server if installed.

No npm installation or build step is required.
For an optional local server, run `python -m http.server 5500` inside this folder, then visit http://localhost:5500.

## Files
- index.html: page content and sections
- style.css: colours, typography, desktop and mobile layouts
- app.js: flavour selection, format selection and saved preferences
- assets/logo.png: DailyFuel logo
- assets/product.png: generated product packaging concept

## Editing
Change copy and formula targets in index.html.
Change the orange colour using --orange in style.css.
Edit flavour names and descriptions in app.js and the matching buttons in index.html.

## Draft status
Product images, flavours, and nutrition targets are concepts. No checkout or email collection is connected. Flavour preferences are saved only in the visitor's browser using localStorage, and are not sent to the brand.
Fonts load from Google Fonts when online; system fonts are used as fallback.
The exported files match the first website draft. Changes made here do not automatically update the hosted site.
